# 数据库初始化说明

## 概述

本目录包含墨渊项目的数据库初始化脚本，用于创建数据库、建表和导入初始数据。

## 文件清单

| 文件 | 说明 | 版本 |
|------|------|------|
| init.sql | 全量初始化脚本（建库 + 建表 + 基础种子数据） | v3.4 |
| 数据库初始化说明文档.md | 本说明文档 | - |

> 历史遗留的 `seed.sql`、`seed-poet-featured.sql`、`seed-su-shi.sql`、`update-poets.sql`、`insert-foreign-poems.sql`、`update-ai-models.sql` 等补充脚本均已合并进 `init.sql`，不再单独提供。
>
> 后续增量变更请放入 `docs/database/migrations/`（该目录已排除 git 提交）。
>
> **注意**：结构性变更（建表、加列、索引、唯一键）的迁移脚本执行后，必须先将变更合并进 `init.sql` 再清理脚本，否则权威定义会出现缺口（v3.4 即因此补齐了 `poet_featured` 的两个唯一键）。一次性数据修复脚本属过渡性文件，效果仅落在本地库，无需合并。

## 使用方法

### 方式一：命令行初始化

```bash
# 进入脚本目录
cd sc-moyuan-backend/src/main/resources/db

# 执行初始化（会提示输入密码）
mysql -u root -p < init.sql
```

### 方式二：MySQL客户端导入

1. 打开MySQL客户端（如Navicat、DBeaver、MySQL Workbench）
2. 连接到MySQL服务器
3. 执行 `init.sql` 文件内容

### 方式三：Spring Boot自动初始化

在 `application.yml` 中配置：

```yaml
spring:
  sql:
    init:
      mode: always
      schema-locations: classpath:db/init.sql
```

> **注意**：此方式仅建议在开发环境使用，生产环境请手动执行初始化。

## 前置条件

- MySQL 8.0+
- 足够的数据库创建权限
- 字符集支持 utf8mb4

## 注意事项

1. **幂等性**：所有建表使用 `IF NOT EXISTS`，数据使用 `INSERT IGNORE`，可重复执行
2. **建库**：`init.sql` 已包含 `CREATE DATABASE IF NOT EXISTS moyuan` 与 `USE moyuan`，无需手动建库
3. **外键约束**：`init.sql` 中未包含外键约束，应用层保证数据一致性
4. **密码加密**：用户密码使用 BCrypt 加密存储
5. **API密钥**：部分 AI 模型的 `api_key` 为占位符（如 `your-deepseek-api-key`），需替换为真实密钥；真实密钥请仅保存在本地，不要提交到仓库
6. **逻辑删除**：大部分表支持逻辑删除（`deleted` 字段）
7. **迁移脚本**：后续增量变更请放入 `docs/database/migrations/`，并同时更新本说明文档
