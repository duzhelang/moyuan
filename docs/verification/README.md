# 独创性开发证明文件（docs/verification）

> 本目录存放"古今诗话——墨渊（SC_MoYuan2）"项目用于软件著作权登记/独创性真实开发证明的材料。
> 生成时间：2026-09-06

## 文件清单

| 文件 | 用途 | 说明 |
|------|------|------|
| `源程序哈希清单.csv` | 源程序文件目录结构（每个文件附哈希值） | 后端 `sc-moyuan-backend/src` 204 个文件 + 前端 `frontend/src` 164 个文件，共 368 个源文件、58,993 行；每行含模块、相对路径、SHA256 哈希、行数、大小 |
| `source-hash-summary.json` | 哈希清单统计摘要 | 生成时间、文件总数、总行数、算法（SHA256） |
| `研发日志.md` | 项目研发日志 | 依据 Git 提交历史整理的分阶段研发记录（2025-05 ~ 2026-09，50 次提交） |
| `代码版本管理记录.txt` | 代码版本管理记录 | Git 完整提交历史（`git log --all`），含 40 位提交哈希、时间戳、作者、提交说明 |

## 复核方法

- 源程序哈希可随时复现：重新运行 `scripts/generate-source-hash.ps1`，将重新扫描源码并计算每个文件的 SHA256，与清单逐条比对即可验证文件未被篡改。
- 版本管理记录可直接执行 `git log --all --format="%H|%ad|%an|%s" --date=format:"%Y-%m-%d %H:%M:%S"` 复核。

## 注意事项

1. 哈希清单按源码快照生成；后续代码发生变更后，需重新运行生成脚本刷新清单，保持与源码一致。
2. `.gitignore` 中包含 `*.csv` 规则，`源程序哈希清单.csv` 如需提交到远程仓库需使用 `git add -f`。
3. 扫描范围仅含源代码（Java/XML/YAML/SQL/Vue/TS/JS/JSON/SCSS/CSS），已排除 `node_modules`、`target`、`dist`、二进制资源（图片/字体等）与构建产物。
