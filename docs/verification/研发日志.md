# 墨渊项目研发日志

> 项目名称：古今诗话——墨渊（SC_MoYuan2）
> 技术栈：Spring Boot 3.x + MyBatis + MySQL 8 + Redis（后端）；Vue 3 + TypeScript + Vite + Element Plus（前端）
> 代码仓库：https://github.com/duzhelang/moyuan.git
> 本日志依据 Git 提交历史（`代码版本管理记录.txt`）与项目文档整理，作为项目独立原创开发的证据

## 一、项目概况

| 项目 | 说明 |
|------|------|
| 项目名称 | 古今诗话——墨渊（SC_MoYuan2） |
| 项目性质 | 中国古典诗词学习与创作平台（Web 全栈应用） |
| 后端 | Spring Boot 3.x + MyBatis-Plus + MySQL 8 + Redis + JWT 双 Token 认证 |
| 前端 | Vue 3（Composition API + `<script setup>`）+ TypeScript + Vite + Element Plus |
| AI 能力 | 多模型接入（智谱 GLM、DeepSeek、Kimi、小米 MiMo、千问 Qwen、OpenRouter、NVIDIA NIM），支持 AI 诗词问答、看图写诗、诗词分析、对对联、AI 内容审核 |
| 开发时间 | 2025-05 至 2026-09（持续迭代） |
| 提交总数 | 50 次（`git log --all` 统计） |
| 源文件规模 | 368 个源文件、58,993 行（见 `源程序哈希清单.csv`） |
