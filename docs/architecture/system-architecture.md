# 古今诗话——墨渊 系统架构文档

## 项目概述

**项目名称**：古今诗话——墨渊（SC\_MoYuan2）

**项目定位**：中国古典诗词文化交流平台，集诗词欣赏、诗人介绍、论坛互动、AI辅助创作于一体的综合性文化网站。

**核心价值**：传承中华诗词文化，提供现代化的诗词学习与交流体验。

### 模块划分

#### 1. 首页模块

- **功能**：轮播图展示、导航菜单、诗人推荐、作品展示、分类精赏、古诗推选、当代精选、论坛预览
- **特点**：响应式布局（4断点适配）、Swiper轮播、组件化架构
- **状态**：前端已实现（views/home/index.vue + components/home/ 子组件）
- **子组件**：HomeCarousel（轮播）、ForumPreview（论坛预览）、AncientPoemSelection（古诗推选）、ContemporaryPoems（当代精选）
- **设计系统**：variables.scss 设计令牌 + mixins.scss 响应式Mixin

#### 2. 诗词模块

- **功能**：诗词浏览、按朝代/流派/诗人分类、诗词详情、注释赏析
- **数据结构**：诗词表、诗人表、朝代表、流派表
- **状态**：前端已实现（views/poem/list.vue, detail.vue）+ 后端 API（sc-moyuan-backend PoemController）

#### 3. 论坛模块

- **功能**：用户发帖、评论互动、精选推荐、投稿上传
- **特点**：富文本编辑、图片上传、实时评论
- **状态**：前端已实现（views/forum/list.vue, detail.vue）+ 后端 API（sc-moyuan-backend ForumController）

#### 4. 用户模块

- **功能**：用户注册、登录认证、个人中心、收藏管理
- **安全**：JWT认证、密码加密、会话管理
- **状态**：前端已实现（views/user/login.vue, register.vue, profile.vue）+ 后端 API（sc-moyuan-backend AuthController）

#### 5. AI模块

- **功能**：AI诗词问答（多模型切换）、看图写诗（视觉模型）、智能诗词分析、AI对对联、AI模型配置管理
- **技术**：调用大语言模型API（智谱AI、DeepSeek、Kimi、NVIDIA NIM），视觉模型（GLM-4V-Flash / GLM-4.6V-Flash）
- **提示词模板**：支持动态变量替换（`{poetName}`、`{poemTitle}`、`{poemContent}`、`{maxLength}`、`{styleHint}`），前端 `buildAiPrompt` 统一构建
- **状态**：已实现（前端首页AI问答组件 + 后端API（AiController）+ AI模型管理（AiModelConfigController））

#### 6. 搜索模块

- **功能**：复合筛选搜索（朝代/分类/诗人/关键词）、诗人模糊输入、智能评分排序、拼音匹配、搜索建议、热门搜索、搜索历史
- **技术**：SmartSearchService（复合查询+评分排序）+ PinyinUtil（拼音匹配）+ Redis（缓存建议/历史/热门）+ MySQL LIKE模糊查询
- **状态**：已实现跨模块搜索（`GET /api/search/smart` 支持多维度复合筛选，诗人下拉框支持自行输入模糊匹配）

#### 7. 管理模块（新增）

- **功能**：系统管理、用户管理、内容管理、数据统计、操作日志、审核管理
- **架构**：前后端分离，管理后台独立布局
- **后端**：AdminController（sc-moyuan-backend模块）
- **前端**：AdminLayout + 管理页面组件（含ECharts图表）
  - 首页仪表盘：admin/index.vue
  - 诗词审核：admin/poem-audit.vue
  - 评论管理：admin/comments.vue
  - 诗人认证：admin/poet-profiles.vue
  - AI内容审核：admin/ai-contents.vue
- **权限**：管理员专属，需要管理员角色认证
- **状态**：已实现

#### 8. 文件模块（新增）

- **功能**：文件上传、图片管理
- **技术**：本地文件存储 + 静态资源映射
- **后端**：FileController + WebMvcConfig

#### 19. 诗云模块（新增）

- **功能**：Three.js 3D 星空可视化，展示中国古诗词数据
  - 诗人星系：每位诗人是一颗发光的星，按朝代分层排列（12个同心壳层）
  - 诗星光点云：每首诗是一个微小光点，围绕在所属诗人星周围
  - 赠诗连线：同朝代诗人之间的关系网络连线
  - 朝代筛选：按朝代过滤诗人和诗词
  - 诗人信息面板：点击诗人星显示诗人信息和代表作品
  - 相机漫游：支持鼠标拖动旋转、滚轮缩放、右键平移
  - 诗体分类着色：五绝/七绝/五律/七律/词/现代诗不同颜色
- **技术方案**：
  - Three.js 渲染引擎（WebGL）
  - OrbitControls 相机控制
  - 自定义 Shader 实现发光效果
  - Points 点云渲染诗词
  - Raycaster 射线检测点击和hover
  - 响应式布局适配移动端
- **前端组件**：poetry-cloud/index.vue
- **API 接口**：GET /api/dynasties、GET /api/poets、GET /api/poems
- **前端路由**：`/poetry-cloud`（诗云星空页面）
- **状态**：前端已实现

## 数据流架构

### 请求流程

```
用户请求 → Nginx(反向代理) → Vue前端 → API请求 → Spring Boot后端 → MySQL/Redis → 返回数据 → 前端渲染
```

### 认证流程

```
用户登录 → 后端验证 → 生成JWT → 返回Token → 前端存储 → 后续请求携带Token → 后端验证Token
```
